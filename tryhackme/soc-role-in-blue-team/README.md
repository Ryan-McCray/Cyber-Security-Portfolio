# SOC Role in Blue Team

**Platform:** TryHackMe

## Objective

Learn how different cybersecurity roles work together within
a Security Operations Center and respond to security incidents.

## Concepts Practiced

- SIEM alert triage
- SOC Level 1 and Level 2 responsibilities
- Incident response
- Threat research
- Vulnerability assessment
- Security engineering
- Governance, Risk, and Compliance (GRC)
- PCI DSS compliance

## Scenario

The lab presented several security incidents and required
identifying the appropriate security professional to handle
each situation.

Examples included:

- Brute-force authentication alerts
- Ransomware incidents
- Phishing and malware investigations
- SIEM infrastructure problems
- PCI DSS audits
- Vulnerability testing
- Threat actor research

## What I Learned

I learned how responsibilities are divided across a security
operations team and how incidents can move between SOC analysts,
incident responders, security engineers, threat researchers,
penetration testers, and GRC personnel.

One important takeaway was understanding the escalation process:
an L1 SOC analyst may perform the initial triage of an alert,
while more complex investigations can require escalation to
higher-tier analysts or incident response teams.
